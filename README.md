# distrust

Manifest o świadomym zaufaniu w sieci. Zbudowany na Zensical, hostowany na Cloudflare Pages.

**Strona:** [distrust.pl](https://distrust.pl/)

---

## Budowanie lokalne

```bash
pip install zensical
zensical serve
```

## Stack

- [Zensical](https://zensical.org/) — generator strony
- Cloudflare Pages — hosting
